Start/end period input

Auto prediction for next period

Ovulation prediction

PMS period highlighting

Irregular cycle handling (AI-based average calculation)

Symptoms (cramps, bloating, acne, cravings, etc.)

Custom symptom creator

Notes (text + voice)

Tags (“PMS”, “work stress”, “date night”)

Calendar View

Monthly overview

Tap to add/edit data

Color-coded cycle stages

Sync with device calendar

Cycle Analytics

Average cycle length, period duration

Graphs of symptoms over time

Predictive trends (“Your last 3 cycles were shorter by 1 day”)

Export as PDF or CSV (for doctor visits)

Period approaching alerts

Ovulation window reminders

Customization
